# GREAT HOLLOW ROUTER

ELDEN RING NIGHTREIGN「大空洞」の**3人マルチ向け結晶候補マップ**です。主な利用環境はiPhoneのSafariです。
開始地点と結晶の有無から基本配置の候補を絞り、地図で確認できます。プレイ中の操作とスクロールを減らし、進路はプレイヤーが判断する設計です。

[公開アプリを開く](https://chocomafia33-dot.github.io/great-hollow-router/)

## 使い方

1. Safariで公開アプリを開き、開始地点を選びます。
   - 南
   - カイデン兵の開始地点
   - 教会の開始地点
2. 地図で示された地点の結晶を「ある」「ない」で回答します。基本配置は**赤・青・緑・紫の4パターン**です。
3. 結果の候補地図を見ながら、ゲーム内で結晶を探します。「地上」「地下」で地図を切り替え、「拡大」「戻す」で表示を切り替えられます。
4. やり直す場合は「再判定」を選びます。

通常の判定は開始地点選択を含め**2〜4回の操作**で終了します。地図切替や拡大の操作はこの回数に含みません。

## 確認できない・配置が合わない場合

### 「未確認」

確認できない地点は「未確認」で飛ばし、別地点を確認できます。同じ判定中には回答済み・未確認の地点を再質問しません。
開始地点選択後の回答は「未確認」を含め**最大3回**です。

「未確認」が一度でも出ると、それ以前の回答も再評価し、**「ない」だけを根拠に配置候補を除外**します。「ある」「未確認」では除外しません。

- 1配置が残る場合：その配置色の◆で候補を表示します。
- 複数配置が残る場合：候補地点の和集合を中立色の◆で表示します。重複地点は1マーカーとし、「未確定」と表示します。
- 4配置が残る場合：全21候補地点を表示します。
- 回答上限・代替質問なしの場合：その時点の候補地図へ進みます。
- 回答が基本配置と矛盾して候補0件の場合：配置を確定せず、全21候補へ退避します。

### 「配置が違う・結晶が見つからない」

結果画面の「その他」から選ぶと、登録済み**全21候補（地上15／地下6）**を表示します。
元の判定候補は◆、その他は灰色の○で区別します。複数配置の場合の◆は中立色です。候補0件からの退避では全地点が中立色◆になります。
切替後は「その他」が自動で閉じ、再度開くこともできます。

**全候補表示は、全地点に結晶が存在するという意味ではありません。**

## iPhone・PWA

Safariで公開URLを開くだけで利用できます。任意で「共有 → ホーム画面に追加」を選ぶと、ホーム画面から起動できます。
オンライン利用を前提とし、オフライン対応は今後の必須要件にはしません。既存のService Workerによるキャッシュは維持しています。
初回読み込みや更新には通信が必要で、すべての端末・状況でのオフライン起動を保証しません。

## データの情報源と限界

- 座標・地上地下区分・配置所属：[Nightreign Hubの大空洞マップ](https://nightreignhub.appforgelabs.com/great-hollow-map)の配布データ（`features/great-hollow/config.ts`）。
- Hubが示す元資料：[The Great Hollow Crystals Definitive Map](https://www.reddit.com/r/Nightreign/comments/1pljy7p/the_great_hollow_crystals_definitive_map/)。
- 通常の判定分岐・開始付近の候補の参考：[Great Hollow 4-crystal route spreadsheetの案内投稿](https://www.reddit.com/r/Nightreign/comments/1rf4jb6/great_hollow_4crystal_route_spreadsheet/)。アプリでは固定ルートを表示しません。

登録された固有地点は21件で、各基本配置に8候補があります。座標は**背景地図画像内の百分率**であり、公式のゲーム内座標ではありません。
日本語の地点名、実際の足場や上下階との対応、ゲーム更新後の配置精度には未確認事項があります。

追加結晶や別配置の混在を示唆する報告があり、4基本パターンが全状況を網羅する保証はありません。
追加結晶による「ある」、見落としや味方の先行回収による「ない」は、判定を誤らせる可能性があります。結果は**配置の候補**として利用してください。

## 開発・自動テスト

静的ファイルをGitHub Pagesで配信しています。アプリに固定攻略ルート、タイマー、役割選択、回収記録、回収数・残数管理、NEXT表示はありません。

Node.js 18以上を用意し、リポジトリのルートで次の1コマンドを実行します。追加パッケージのインストール・外部通信は不要です。

```sh
node --test tests/*.test.cjs
```

テスト失敗時は開始地点・配置・回答経路などを名前で表示し、終了コードが非0になります。
通常12通り、未確認を含む全回答経路、候補の統合、地上地下表示、全候補表示、再判定、拡大、PWAの基本処理を検証します。
矛盾・代替質問なしの防御処理は、テスト環境だけで状態や関数を差し替えて確認します。本番コードは書き換えません。

テストは簡易DOMとService Workerの模擬環境です。ブラウザでの描画、タップのしやすさ、iPhone端末内キャッシュ、実ゲームの配置精度を保証するものではありません。
仕様の基準は2026年10月10日版の開発引き継ぎ資料です。通信・オフライン方針にはその後の確定方針も反映しています。
座標・配置を意図的に変更するときは、レビュー後にテストの期待値も更新してください。
